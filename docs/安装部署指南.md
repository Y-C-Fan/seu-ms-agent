## 1. 系统要求

### 1.1 硬件要求

| 项目 | 最低配置 | 推荐配置 |
|-----|---------|---------|
| **CPU** | 双核 2.0GHz | 四核 3.0GHz+ |
| **内存** | 4GB RAM | 8GB+ RAM |
| **硬盘** | 10GB 可用空间 | 20GB+ SSD |
| **网络** | 稳定网络连接 | 高速网络连接 |

### 1.2 软件要求

| 软件 | 版本要求 | 说明 |
|-----|---------|------|
| **操作系统** | Linux / macOS / Windows | Windows需要WSL2 |
| **Python** | 3.10+ | 必须安装pip |
| **Git** | 2.0+ | 用于克隆仓库 |
| **pip** | 最新版本 | Python包管理器 |

### 1.3 必需的API Key

至少需要以下API Key之一：

- ✅ **OpenAI API Key** (推荐): 用于GPT-4o等模型
- ✅ **ModelScope API Key**: 用于Qwen等模型
- 🟡 **Exa API Key** (可选): 用于增强搜索
- 🟡 **SerpAPI Key** (可选): Google搜索备用

## 2. 快速安装

### 2.1 一键安装脚本（推荐）

```bash
# 克隆仓库
git clone https://github.com/Y-C-Fan/seu-ms-agent.git
cd seu-ms-agent

# 运行安装脚本
bash scripts/install.sh

# 配置API Key
cp .env.example .env
nano .env  # 编辑并填入你的API Key

# 验证安装
python3 orchestrator/main.py --help
```

### 2.2 Docker安装（推荐生产环境）

```bash
# 拉取镜像
docker pull seu-ms-agent:latest

# 运行容器
docker run -it \
  -e OPENAI_API_KEY="your-key" \
  -v $(pwd)/workspace:/app/workspace \
  seu-ms-agent:latest

# 或使用docker-compose
docker-compose up -d
```

## 3. 详细安装步骤

### 3.1 Step 1: 环境准备

#### 3.1.1 检查Python版本

```bash
python3 --version
# 应该显示 Python 3.10.x 或更高

# 如果版本过低，安装Python 3.10+
# Ubuntu/Debian:
sudo apt update
sudo apt install python3.10 python3.10-venv python3-pip

# macOS (使用Homebrew):
brew install python@3.10

# Windows:
# 从 https://www.python.org/downloads/ 下载安装
```

#### 3.1.2 安装Git

```bash
# Ubuntu/Debian:
sudo apt install git

# macOS:
brew install git

# Windows:
# 从 https://git-scm.com/download/win 下载安装
```

### 3.2 Step 2: 克隆仓库

```bash
# HTTPS方式（推荐）
git clone https://github.com/Y-C-Fan/seu-ms-agent.git

# 或SSH方式
git clone git@github.com:Y-C-Fan/seu-ms-agent.git

# 进入项目目录
cd seu-ms-agent

# 切换到稳定分支
git checkout main
```

### 3.3 Step 3: 创建虚拟环境（推荐）

```bash
# 创建虚拟环境
python3 -m venv venv

# 激活虚拟环境
# Linux/macOS:
source venv/bin/activate

# Windows:
venv\Scripts\activate

# 升级pip
pip install --upgrade pip
```

### 3.4 Step 4: 安装依赖

#### 3.4.1 基础安装（仅核心功能）

```bash
pip install -r requirements/framework.txt
```

#### 3.4.2 完整安装（包含所有功能）

```bash
# 安装所有依赖
pip install -r requirements/framework.txt
pip install -r requirements/research.txt
pip install -r requirements/code.txt

# 或一次性安装
pip install -r requirements.txt
```

#### 3.4.3 开发环境安装（包含开发工具）

```bash
pip install -r requirements/framework.txt
pip install -r requirements/research.txt
pip install -r requirements/code.txt
pip install -r requirements/dev.txt  # 包含pytest, black, flake8等
```

### 3.5 Step 5: 配置环境变量

#### 3.5.1 复制配置模板

```bash
cp .env.example .env
```

#### 3.5.2 编辑配置文件

```bash
# 使用你喜欢的编辑器
nano .env
# 或
vim .env
# 或
code .env  # VS Code
```

#### 3.5.3 配置示例

```.env
# ===== 必需配置 =====

# OpenAI配置（推荐）
OPENAI_API_KEY=sk-your-openai-api-key-here
OPENAI_BASE_URL=https://api.openai.com/v1

# 或使用ModelScope（国内用户推荐）
MODELSCOPE_API_KEY=your-modelscope-api-key-here
OPENAI_BASE_URL=https://api-inference.modelscope.cn/v1/

# ===== 可选配置 =====

# 搜索引擎API（可选）
EXA_API_KEY=your-exa-api-key-here
SERPAPI_API_KEY=your-serpapi-key-here

# 模型配置
MODEL_NAME=gpt-4o  # 或 Qwen/Qwen2.5-Coder-32B-Instruct

# 运行配置
MAX_RETRIES=3
WORKSPACE_ROOT=workspace
LOG_LEVEL=INFO

# ===== 高级配置 =====

# 代理设置（如需要）
HTTP_PROXY=http://proxy.example.com:8080
HTTPS_PROXY=http://proxy.example.com:8080

# 超时设置
LLM_TIMEOUT=300
RESEARCH_TIMEOUT=600
CODE_TIMEOUT=300
```

### 3.6 Step 6: 验证安装

```bash
# 检查安装
python3 -c "import ms_agent; print(ms_agent.__version__)"

# 测试CLI
python3 orchestrator/main.py --help

# 运行简单测试
python3 orchestrator/main.py "Hello, test" --mode research_only
```

## 4. 配置说明

### 4.1 API Key获取

#### 4.1.1 OpenAI API Key

1. 访问 https://platform.openai.com
2. 注册/登录账号
3. 进入 API Keys 页面
4. 点击 "Create new secret key"
5. 复制生成的Key（以`sk-`开头）

**价格参考**:
- GPT-4o: $5/1M input tokens, $15/1M output tokens
- GPT-4o-mini: $0.15/1M input tokens, $0.60/1M output tokens

#### 4.1.2 ModelScope API Key（国内推荐）

1. 访问 https://modelscope.cn
2. 注册/登录账号
3. 进入个人中心 > API Token
4. 创建新Token
5. 复制Token

**优势**:
- 国内访问速度快
- 支持Qwen等开源模型
- 价格更优惠

#### 4.1.3 Exa API Key（可选）

1. 访问 https://exa.ai
2. 注册账号
3. 获取API Key
4. 用于增强Web搜索能力

### 4.2 配置文件详解

#### 4.2.1 Orchestrator配置

**位置**: `orchestrator/core/config.py`

```python
# 可以通过代码覆盖默认配置
config = OrchestratorConfig(
    openai_api_key="sk-xxx",
    model_name="gpt-4o",
    max_retries=3,
    workspace_root="workspace"
)
```

#### 4.2.2 Agent配置

**Spec Agent配置**: `wyh_test/configs/spec_agent.yaml`

```yaml
llm:
  model: "gpt-4o"
  api_key: ${OPENAI_API_KEY}  # 从环境变量读取
  temperature: 0.3
  max_tokens: 4096

retry:
  max_attempts: 3
  backoff_factor: 2

output:
  validation:
    enabled: true
```

**Test Agent配置**: `wyh_test/configs/test_agent.yaml`

```yaml
llm:
  model: "gpt-4o"
  api_key: ${OPENAI_API_KEY}
  temperature: 0.5
  max_tokens: 4096

test_generation:
  include_fixtures: true
  include_mocks: true
  coverage_target: 0.80
```

### 4.3 代理配置（可选）

如果你在国内或需要通过代理访问API：

```bash
# 方法1: 环境变量
export HTTP_PROXY=http://proxy.example.com:8080
export HTTPS_PROXY=http://proxy.example.com:8080

# 方法2: .env文件
# 在.env中添加
HTTP_PROXY=http://proxy.example.com:8080
HTTPS_PROXY=http://proxy.example.com:8080

# 方法3: Python代码
import os
os.environ['HTTP_PROXY'] = 'http://proxy.example.com:8080'
os.environ['HTTPS_PROXY'] = 'http://proxy.example.com:8080'
```

## 6. 常见问题

### 6.1 安装问题

#### Q1: `pip install`失败，提示网络错误

**解决方案**:

```bash
# 方法1: 使用国内镜像源
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 方法2: 配置永久镜像源
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

# 方法3: 升级pip
pip install --upgrade pip
```

#### Q2: Python版本不兼容

**解决方案**:

```bash
# 使用pyenv管理多个Python版本
curl https://pyenv.run | bash

# 安装Python 3.10
pyenv install 3.10.13
pyenv local 3.10.13

# 重新创建虚拟环境
python3 -m venv venv
source venv/bin/activate
```

#### Q3: 依赖包版本冲突

**解决方案**:

```bash
# 清理缓存
pip cache purge

# 使用干净的虚拟环境
rm -rf venv
python3 -m venv venv
source venv/bin/activate

# 重新安装
pip install -r requirements.txt
```

### 6.2 配置问题

#### Q4: API Key不生效

**排查步骤**:

```bash
# 检查环境变量
echo $OPENAI_API_KEY

# 检查.env文件
cat .env | grep OPENAI_API_KEY

# 测试API Key
python3 -c "
import os
from dotenv import load_dotenv
load_dotenv()
print(os.getenv('OPENAI_API_KEY'))
"

# 如果为空，手动加载
export $(cat .env | xargs)
```

#### Q5: 代理配置不生效

**解决方案**:

```bash
# 测试代理连接
curl -x http://proxy.example.com:8080 https://api.openai.com

# 在Python中测试
python3 -c "
import os
import requests
os.environ['HTTP_PROXY'] = 'http://proxy.example.com:8080'
response = requests.get('https://api.openai.com')
print(response.status_code)
"
```

### 6.3 运行问题

#### Q6: 运行时提示找不到模块

**解决方案**:

```bash
# 确保在项目根目录
pwd
# 应该显示 /path/to/seu-ms-agent

# 添加到Python路径
export PYTHONPATH="${PYTHONPATH}:$(pwd)"

# 或在代码中添加
import sys
sys.path.append('/path/to/seu-ms-agent')
```

#### Q7: 权限错误

**解决方案**:

```bash
# 检查工作区权限
ls -la workspace/

# 修复权限
chmod -R 755 workspace/
chown -R $USER:$USER workspace/

# 如果是Docker，映射用户ID
docker run -it \
  -u $(id -u):$(id -g) \
  -v $(pwd)/workspace:/app/workspace \
  seu-ms-agent:latest
```

### 6.4 性能问题

#### Q8: 运行速度很慢

**优化建议**:

```bash
# 1. 使用更快的模型
# 在.env中设置
MODEL_NAME=gpt-4o-mini  # 比gpt-4o快3倍

# 2. 减少搜索结果数量
# 修改配置
MAX_SEARCH_RESULTS=5  # 默认10

# 3. 跳过人工审查（自动模式）
python3 orchestrator/main.py "query" --no-human-review

# 4. 使用本地模型（未来支持）
# MODEL_NAME=local/qwen2.5-coder
```

## 9. Docker部署（高级）

### 9.1 构建镜像

```dockerfile
# Dockerfile
FROM python:3.10-slim

WORKDIR /app

# 安装系统依赖
RUN apt-update && apt-get install -y \
    git \
    && rm -rf /var/lib/apt/lists/*

# 复制依赖文件
COPY requirements/ requirements/
RUN pip install --no-cache-dir -r requirements/framework.txt \
    && pip install --no-cache-dir -r requirements/research.txt \
    && pip install --no-cache-dir -r requirements/code.txt

# 复制项目文件
COPY . .

# 设置环境变量
ENV PYTHONPATH=/app
ENV WORKSPACE_ROOT=/app/workspace

# 创建工作区
RUN mkdir -p workspace

# 入口点
ENTRYPOINT ["python3", "orchestrator/main.py"]
```

**构建命令**:

```bash
docker build -t seu-ms-agent:v1.0 .
```

### 9.2 运行容器

```bash
# 交互式运行
docker run -it --rm \
  -e OPENAI_API_KEY="your-key" \
  -v $(pwd)/workspace:/app/workspace \
  seu-ms-agent:v1.0 \
  "Build a calculator" --mode full

# 后台运行
docker run -d \
  --name ms-agent-task \
  -e OPENAI_API_KEY="your-key" \
  -v $(pwd)/workspace:/app/workspace \
  seu-ms-agent:v1.0 \
  "Build a calculator" --mode full

# 查看日志
docker logs -f ms-agent-task
```

### 9.3 docker-compose配置

```yaml
# docker-compose.yml
version: '3.8'

services:
  ms-agent:
    build: .
    image: seu-ms-agent:v1.0
    container_name: ms-agent
    environment:
      - OPENAI_API_KEY=${OPENAI_API_KEY}
      - MODEL_NAME=${MODEL_NAME:-gpt-4o}
    volumes:
      - ./workspace:/app/workspace
      - ./.env:/app/.env
    command: ["--help"]
```

**运行**:

```bash
docker-compose up
```
