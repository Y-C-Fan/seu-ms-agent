## 1. 概述

### 1.1 系统简介

Research-to-Code Pipeline 是一个基于MS-Agent框架的自动化代码生成系统，实现从"自然语言需求"到"可运行的Repository级代码"的端到端流程。

**核心能力**:
- 自主研究：联网搜索和文档分析
- 规范生成：将研究成果转化为技术规格
- 测试驱动：先生成测试用例
- 代码实现：基于规范和测试生成代码
- 自我验证：自动运行测试并修复错误

### 1.2 设计原则

1. **无侵入性 (Non-Invasive)**: 不修改MS-Agent框架源码，通过Adapter模式集成
2. **模块化 (Modularity)**: 各阶段独立，可单独替换和升级
3. **可观测性 (Observability)**: 每个阶段产出可见的中间文件
4. **可控性 (Controllability)**: 支持Human-in-the-Loop人工审查
5. **可扩展性 (Extensibility)**: 通过Hook和Plugin机制轻松扩展
6. **容错性 (Fault Tolerance)**: 异常处理、重试机制、降级策略

### 1.3 系统边界

**包含的功能**:
- ✅ 多模态文档理解（PDF/PPT/DOCX/TXT）
- ✅ Web搜索和知识提取
- ✅ 技术规范生成
- ✅ 测试用例生成
- ✅ 代码生成和验证
- ✅ Human-in-the-Loop交互

**不包含的功能**:
- ❌ 代码运行时环境（需用户自行准备Python环境）
- ❌ 生产环境部署（仅生成代码，不部署）
- ❌ 项目管理功能（任务分配、进度跟踪等）

### 2.2 架构层次说明

#### 2.2.1 用户界面层 (User Interface Layer)

**职责**: 接收用户输入，展示执行结果

**组件**:
- **CLI (命令行界面)**: 
  - 位置: `orchestrator/main.py`
  - 功能: 接收参数、解析命令、调用Orchestrator
  - 示例: `python3 orchestrator/main.py "Build a calculator"`

- **Web UI (未实现，预留接口)**:
  - 计划使用Gradio/Streamlit
  - 提供更友好的交互界面

- **API Gateway (未实现，预留接口)**:
  - RESTful API
  - 支持远程调用

#### 2.2.2 编排层 (Orchestrator Layer)

**职责**: 全局流程控制、状态管理、错误处理

**组件**:

1. **FlowController** (`orchestrator/core/flow.py`):
   - 实现Human-in-the-Loop机制
   - 在关键节点暂停，等待用户审查
   - 支持Continue/Reload/Exit三种操作

2. **WorkspaceManager** (`orchestrator/core/workspace.py`):
   - 管理工作目录（创建、清理、路径解析）
   - 每次运行创建独立的`workspace/run_YYYYMMDD_HHMMSS/`目录
   - 防止任务间文件冲突

3. **ConfigManager** (`orchestrator/core/config.py`):
   - 统一管理配置（API Key、模型名称、重试次数）
   - 支持环境变量和.env文件
   - 配置验证和默认值

4. **Logger** (`orchestrator/utils/logger.py`):
   - 双路日志：Console（简洁）+ File（详细）
   - 日志级别：DEBUG/INFO/WARNING/ERROR
   - 关键节点打点（Token消耗、执行时间）

#### 2.2.3 适配器层 (Adapter Layer)

**职责**: 封装外部模块，提供统一接口

**设计模式**: Adapter Pattern

**基类定义**:
```python
class BaseAdapter(ABC):
    @abstractmethod
    def run(self, **kwargs) -> Dict[str, Any]:
        """执行适配器逻辑"""
        pass
```

**具体适配器**:

1. **ResearchAdapter** (2种实现):
   - `DocResearchAdapter`: 处理附件/URL，调用`ms_agent/workflow/ResearchWorkflow`
   - `DeepResearchAdapter`: 无附件时，调用`projects/deep_research`联网搜索

2. **SpecAdapter** (`orchestrator/adapters/spec_adapter.py`):
   - 调用`wyh_test/agents/spec_generator_agent.py`
   - 将report.md转为tech_spec.md

3. **TestGenAdapter** (`orchestrator/adapters/test_gen_adapter.py`):
   - 调用`wyh_test/agents/test_generator_agent.py`
   - 基于tech_spec.md生成tests/

4. **CodeAdapter** (`orchestrator/adapters/code_adapter.py`):
   - 调用`external_integration/code_scratch_caller.py`
   - 通过subprocess调用`projects/code_scratch`

#### 2.2.4 MS-Agent框架层

**职责**: 提供底层AI能力

**核心模块**:
- **LLMAgent**: 封装LLM调用（OpenAI/Anthropic/ModelScope）
- **Workflow**: ChainWorkflow（线性+循环）、DagWorkflow（DAG并行）
- **Memory**: 基于mem0的长短期记忆
- **RAG**: 基于LlamaIndex的多模态检索
- **Tools**: 工具调用框架
- **MCP**: Model Context Protocol支持
- **Callback**: 生命周期钩子

```python
    text = extract_text(file_path)
```

```python
def validate_spec_format(spec_content: str) -> Tuple[bool, List[str]]:
    """
    验证技术规范的格式和完整性
    
    返回:
        (is_valid, issues)
    """
    issues = []
    
    # 必需章节
    required_sections = [
        "Executive Summary",
        "System Architecture",
        "API Specifications",
        "Data Models",
        "Dependencies",
        "Testing Considerations"
    ]
    
    for section in required_sections:
        if section not in spec_content:
            issues.append(f"缺失章节: {section}")
    
    # API签名检查
    if not contains_type_hints(spec_content):
        issues.append("API定义缺少类型标注")
    
    return len(issues) == 0, issues
```

#### 3.4.3 外循环验证算法

```python
def outer_loop_verification(
    spec_path: Path,
    tests_dir: Path,
    max_retries: int = 3
) -> Dict[str, Any]:
    """
    外循环验证：生成代码 → 测试 → 重试
    """
    for attempt in range(1, max_retries + 1):
        logger.info(f"尝试 {attempt}/{max_retries}")
        
        # 1. 生成代码
        prompt = construct_prompt(spec_path, tests_dir, attempt)
        code = code_generator.generate(prompt)
        
        # 2. 运行测试
        result = test_runner.run(tests_dir)
        
        if result.success:
            logger.info("测试通过！")
            return {'success': True, 'attempts': attempt}
        
        # 3. 解析错误
        errors = parse_pytest_errors(result.stderr)
        logger.warning(f"测试失败: {errors}")
        
        # 4. 构造反馈
        feedback = f"""
        测试失败，错误信息：
        {format_errors(errors)}
        
        【提示】:
        - 检查变量类型是否正确
        - 检查边界条件处理
        - 检查import语句是否完整
        
        请修复代码。
        """
    
    return {'success': False, 'attempts': max_retries}
```

## 5. 接口设计

### 5.1 Adapter接口

```python
from abc import ABC, abstractmethod
from typing import Any, Dict
from pathlib import Path

class BaseAdapter(ABC):
    """
    适配器基类，所有Phase的Adapter必须继承此类
    """
    
    def __init__(self, config: OrchestratorConfig, workspace: WorkspaceManager):
        self.config = config
        self.workspace = workspace
    
    @abstractmethod
    def run(self, **kwargs) -> Dict[str, Any]:
        """
        执行适配器逻辑
        
        返回:
            Dict包含:
                - success: bool
                - output_path: Path (主要输出文件)
                - metadata: Dict (额外信息)
        """
        pass
    
    def validate_inputs(self, **kwargs) -> bool:
        """验证输入参数"""
        return True
    
    def cleanup(self):
        """清理临时资源"""
        pass
```

## 10. 扩展性设计

### 10.1 Hook机制

```python
class HookRegistry:
    """全局Hook注册表"""
    
    hooks = {
        'pre_research': [],
        'post_research': [],
        'pre_spec': [],
        'post_spec': [],
        'pre_test': [],
        'post_test': [],
        'pre_code': [],
        'post_code': []
    }
    
    @classmethod
    def register(cls, hook_name: str, func: Callable):
        """注册Hook"""
        cls.hooks[hook_name].append(func)
    
    @classmethod
    def trigger(cls, hook_name: str, **kwargs):
        """触发Hook"""
        for func in cls.hooks.get(hook_name, []):
            func(**kwargs)

# 使用示例
def validate_spec_security(spec_path: Path):

HookRegistry.register('post_spec', validate_spec_security)
```

### 10.2 插件系统

```python
class Plugin(ABC):
    """插件基类"""
    
    @abstractmethod
    def on_load(self):
        """插件加载时调用"""
        pass
    
    @abstractmethod
    def execute(self, context: Dict) -> Dict:
        """插件执行逻辑"""
        pass

# 插件加载器
class PluginLoader:
    def load_plugins(self, plugin_dir: Path):
        """动态加载plugins目录下的所有插件"""
        for file in plugin_dir.glob('*.py'):
            module = import_module(file.stem)
            plugin_class = getattr(module, 'Plugin')
            plugin = plugin_class()
            plugin.on_load()
            self.plugins.append(plugin)
```
