## 2. 数据流程图

### 2.1 端到端数据流

```mermaid
flowchart TD
    Start([用户输入]) --> Input{有附件?}
    
    Input -->|有| DocResearch[文档研究]
    Input -->|无| DeepResearch[深度研究]
    
    DocResearch --> ParseDoc[解析文档]
    ParseDoc --> ExtractText[提取文本]
    ParseDoc --> ExtractImg[提取图片]
    ParseDoc --> ExtractTable[提取表格]
    
    ExtractImg --> VisionLLM[视觉LLM理解]
    VisionLLM --> MergeContent
    ExtractText --> MergeContent[合并内容]
    ExtractTable --> MergeContent
    
    DeepResearch --> WebSearch[网络搜索]
    WebSearch --> FilterResults[筛选结果]
    FilterResults --> MergeContent
    
    MergeContent --> Report[生成报告<br/>report.md]
    
    Report --> HITL1{人工审查?}
    HITL1 -->|继续| SpecLLM[LLM生成规范]
    HITL1 -->|修改| Report
    
    SpecLLM --> ValidateSpec{验证格式}
    ValidateSpec -->|失败| SpecLLM
    ValidateSpec -->|通过| Spec[tech_spec.md]
    
    Spec --> HITL2{人工审查?}
    HITL2 -->|继续| TestLLM[LLM生成测试]
    HITL2 -->|修改| Spec
    
    TestLLM --> Tests[tests/]
    
    Tests --> PromptInject[Prompt注入]
    Spec --> PromptInject
    PromptInject --> CodeLLM[LLM生成代码]
    
    CodeLLM --> Code[src/]
    Code --> RunTest[运行测试]
    
    RunTest --> TestResult{测试通过?}
    TestResult -->|失败| ParseError[解析错误]
    ParseError --> RetryCount{重试<3次?}
    RetryCount -->|是| CodeLLM
    RetryCount -->|否| ManualFix[需要人工修复]
    
    TestResult -->|通过| Success([交付成功])
    
    style Report fill:#c8e6c9
    style Spec fill:#bbdefb
    style Tests fill:#fff9c4
    style Code fill:#ffccbc
    style Success fill:#a5d6a7
```

### 2.2 外循环验证流程

```mermaid
flowchart TD
    Start([开始代码生成]) --> GenCode[生成代码]
    GenCode --> Save[保存到src/]
    Save --> RunPytest[运行pytest]
    
    RunPytest --> CheckResult{测试结果}
    
    CheckResult -->|全部通过| Success([成功交付])
    
    CheckResult -->|有失败| ParseError[解析错误信息]
    ParseError --> ExtractStack[提取堆栈跟踪]
    ExtractStack --> IdentifyIssue[识别问题类型]
    
    IdentifyIssue --> IssueType{问题类型}
    
    IssueType -->|语法错误| SyntaxFix[语法修复提示]
    IssueType -->|逻辑错误| LogicFix[逻辑修复提示]
    IssueType -->|导入错误| ImportFix[导入修复提示]
    
    SyntaxFix --> BuildPrompt[构建Retry Prompt]
    LogicFix --> BuildPrompt
    ImportFix --> BuildPrompt
    
    BuildPrompt --> CheckRetry{重试次数<3?}
    CheckRetry -->|是| GenCode
    CheckRetry -->|否| MaxRetry[达到最大重试次数]
    MaxRetry --> HumanIntervene([需要人工介入])
    
    style Success fill:#4caf50,color:#fff
    style HumanIntervene fill:#ff9800,color:#fff
    style MaxRetry fill:#f44336,color:#fff
```

    rect rgb(232, 245, 233)
        Note over Orch,SA: Phase 2: Spec Generation
        Orch->>SA: run(report.md)
        SA->>LLM: 生成技术规范
        LLM-->>SA: tech_spec.md
        SA->>SA: 验证格式
        SA->>FS: 保存tech_spec.md
        FS-->>Orch: tech_spec.md

    User-->>Orch: ✅ 确认继续
    
    rect rgb(227, 242, 253)
        Note over Orch,TA: Phase 3: Test Generation
        Orch->>TA: run(tech_spec.md)
        TA->>LLM: 生成测试用例
        LLM-->>TA: test_*.py
        TA->>FS: 保存tests/
        FS-->>Orch: tests/
    end
    
    rect rgb(255, 243, 224)
        Note over Orch,CA: Phase 4: Code & Verify
        loop 最多3次
            Orch->>CA: run(spec, tests)
            CA->>LLM: 生成代码

            CA->>FS: 保存src/

### 3.2 Human-in-the-Loop交互时序

```mermaid
sequenceDiagram
    participant Orch as Orchestrator
    participant Flow as FlowController
    participant FS as 文件系统
    actor User as 用户
    
    Orch->>Flow: wait_for_human_review("tech_spec.md")
    Flow->>FS: 读取文件路径
    FS-->>Flow: /workspace/run_xxx/tech_spec.md
    
    Flow->>User: 🛑 请审查文件
    Flow->>User: 选项: [C]ontinue / [R]eload / [E]xit
    
    alt 用户选择 Continue
        User->>Flow: C
        Flow-->>Orch: True (继续)
    else 用户选择 Reload
        User->>Flow: R
        Flow->>FS: 读取文件内容
        FS-->>Flow: 文件内容
        Flow->>User: 📄 显示预览
        Flow->>User: 选项: [C]ontinue / [R]eload / [E]xit
    else 用户选择 Exit
        User->>Flow: E
        Flow-->>Orch: False (终止)
        Orch->>Orch: 清理资源
        Orch->>User: 任务已取消
    end
```

## 7. 错误处理流程

```mermaid
flowchart TD
    Start([开始执行]) --> TryExec{执行操作}
    
    TryExec -->|成功| Success([成功])
    TryExec -->|异常| CatchError[捕获异常]
    
    CatchError --> ClassifyError{异常类型}
    
    ClassifyError -->|网络错误| NetworkRetry[重试机制]
    ClassifyError -->|API错误| APIFallback[切换备用服务]
    ClassifyError -->|验证错误| ValidationFix[修复输入]
    ClassifyError -->|系统错误| SystemLog[记录日志]
    
    NetworkRetry --> RetryCount{重试次数}
    RetryCount -->|<3次| TryExec
    RetryCount -->|>=3次| FallbackOrFail
    
    APIFallback --> TryExec
    ValidationFix --> TryExec
    
    SystemLog --> FallbackOrFail{有降级方案?}
    FallbackOrFail -->|有| UseFallback[使用降级方案]
    FallbackOrFail -->|无| Fail([失败])
    
    UseFallback --> Success
    
    style Success fill:#4caf50,color:#fff
    style Fail fill:#f44336,color:#fff
```

## 附录：图例说明

### 颜色编码

- 🟦 **蓝色**: 输入/输出相关
- 🟩 **绿色**: 成功状态
- 🟨 **黄色**: 处理中状态
- 🟧 **橙色**: 警告/注意
- 🟥 **红色**: 错误/失败

### 符号说明

- `-->` : 数据流/控制流
- `-.->` : 可选流程/未来扩展
- `[]` : 进程/模块
- `()` : 开始/结束
- `{}` : 决策点
- `[()]` : 事件
