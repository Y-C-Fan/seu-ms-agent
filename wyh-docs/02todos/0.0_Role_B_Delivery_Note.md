## 2. 完成工作总结 (Summary of Work)

### 2.1 核心成果

1. **SpecGeneratorAgent** (spec_generator_agent.py, 314 lines):

   - 基于 `ms_agent.LLMAgent` 实现
   - 使用 SOTA 模型 (GPT-4o/Claude-3.5-Sonnet)
   - 将自然语言研究报告转换为结构化技术规范
   - 内置验证和重试机制 (最多 3 次尝试)
   - 支持同步/异步调用

2. **TestGeneratorAgent** (test_generator_agent.py, 429 lines):

   - 遵循 AlphaCodium 的 Test-Driven 模式
   - 生成全面的 pytest 测试套件
   - 支持 TDD: 测试在实现前可运行 (使用 pytest.skip)
   - 自动创建 conftest.py 和共享 fixtures
   - 输出验证确保测试质量

3. **适配器集成**:

   - `SpecAdapter` 和 `TestGenAdapter` 实现 `BaseAdapter` 接口
   - 完全兼容现有 orchestrator 框架
   - 无缝替换 Mock 实现
   - 统一的错误处理和日志记录

4. **提示词工程** (prompts.py, 440 lines):

   - `SPEC_GENERATION_PROMPT`: 引导 LLM 生成高质量技术规范
   - `TEST_GENERATION_PROMPT`: 确保测试覆盖 happy path、edge cases 和 errors
   - 包含详细的输出格式说明和示例

5. **质量保证** (validators.py, 214 lines):
   - `validate_spec_format()`: 检查规范完整性
   - `validate_test_format()`: 验证测试文件符合 pytest 规范
   - 自动重试机制处理验证失败

## 3. 使用指南 (User Guide)

### 3.1 环境准备

确保安装了项目依赖：

```bash
pip install -r requirements/framework.txt
# 如遇到导入错误，安装以下依赖
pip install pandas omegaconf
```

设置必要的环境变量：

```bash
export OPENAI_API_KEY="sk-xxx"
# 或者使用其他模型服务
# export DASHSCOPE_API_KEY="xxx"
```

### 3.2 通过 Orchestrator 使用（推荐）

Role B 的组件将通过 Role A 的 orchestrator 自动调用：

```bash
cd /workspaces/seu-ms-agent

# 完整流程: Research -> Spec -> Test -> Code
python3 orchestrator/main.py "Build a REST API for todo management"

# 基于文档的分析
python3 orchestrator/main.py "Implement the algorithm" --files ./paper.pdf

# 仅运行研究阶段（不生成 Spec 和 Test）
python3 orchestrator/main.py "AI trends analysis" --mode research_only
```

### 3.3 独立使用

也可以独立使用 Spec/Test 生成功能：

**生成技术规范：**

```python
from pathlib import Path
from wyh_test.agents.spec_generator_agent import SpecGeneratorAgent

# 初始化 Agent
agent = SpecGeneratorAgent(model='gpt-4o')

# 生成 Spec（同步方式）
result = agent.generate_spec_sync(
    report_path=Path('workspace/run_xxx/report.md'),
    output_path=Path('workspace/run_xxx/tech_spec.md')
)

print(f"Spec generated: {result['spec_path']}")
print(f"Valid: {result['is_valid']}")
```

**生成测试用例：**

```python
from pathlib import Path
from wyh_test.agents.test_generator_agent import TestGeneratorAgent

# 初始化 Agent
agent = TestGeneratorAgent(model='gpt-4o')

# 生成 Tests（同步方式）
result = agent.generate_tests_sync(
    spec_path=Path('workspace/run_xxx/tech_spec.md'),
    output_dir=Path('workspace/run_xxx/tests')
)

print(f"Tests directory: {result['tests_dir']}")
print(f"Generated {len(result['test_files'])} test files")
```

## 4. 给 Role A & C 的协作说明

### 4.1 与 Role A (Orchestrator) 的协作

- **输入接口**: 接收 Role A 提供的 `report.md`
- **输出接口**: 向 orchestrator 返回 `tech_spec.md` 和 `tests/` 目录
- **适配器集成**: 通过 `BaseAdapter` 标准接口集成
- **错误处理**: 验证失败时自动重试，最终失败时抛出异常供 orchestrator 处理

### 4.2 与 Role C (Coding Agent) 的协作

- **输出交付**: 为 Role C 提供：
  - `tech_spec.md` - 代码实现的详细蓝图
  - `tests/` - 代码必须通过的测试套件
- **验证支持**: Role C 生成的代码会被 Role B 的测试验证
- **反馈循环**: 如测试失败，错误信息会反馈给 Role C 用于修复

### 4.3 依赖关系说明

**重要**: `wyh_test/` 目录不能删除！

orchestrator 中的适配器依赖 wyh_test 模块：

```python
# orchestrator/adapters/spec_adapter.py
from wyh_test.agents.spec_generator_agent import SpecGeneratorAgent

# orchestrator/adapters/test_gen_adapter.py
from wyh_test.agents.test_generator_agent import TestGeneratorAgent
```

## 5. 配置说明

### 5.1 Spec Agent 配置

文件：`wyh_test/configs/spec_agent.yaml`

关键参数：

```yaml
llm:
  model: "gpt-4o" # 推荐使用高质量模型
  temperature: 0.3 # 较低温度确保输出一致性
  max_tokens: 8000 # Spec 可能较长

retry:
  max_attempts: 3 # 验证失败时重试次数
```

### 5.2 Test Agent 配置

文件：`wyh_test/configs/test_agent.yaml`

关键参数：

```yaml
llm:
  model: "gpt-4o"
  temperature: 0.4 # 稍高温度增加测试多样性
  max_tokens: 12000 # 测试套件通常很长
```

## 6. 故障排查

### 问题 1: ModuleNotFoundError: No module named 'pandas'

**原因**: ms_agent 框架的某些工具依赖 pandas  
**解决**:

```bash
pip install pandas
```

### 问题 2: API Key 错误

**现象**: `ValueError: API Key is missing`  
**解决**:

```bash
export OPENAI_API_KEY="your-key"
```

### 问题 3: Spec/Test 生成质量不佳

**原因**: 模型选择或温度参数不当  
**解决**:

- 使用 `gpt-4o` 或 `claude-3-5-sonnet` 等高质量模型
- 调整 `wyh_test/configs/*.yaml` 中的参数

### 问题 4: 验证失败

**现象**: Agent 重试 3 次后仍失败  
**解决**:

- 检查 report.md 内容是否完整
- 查看日志文件了解具体验证错误
- 手动调整生成的 spec/test 文件
